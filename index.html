Worldguess

Google Street View gives the best imagery and needs your own Google Maps key; Google's free monthly allowance covers normal play. The photo modes need no key.

Set up your key (once)

  1. In Google Cloud Console, create a project and enable Maps JavaScript API.
  2. Create an API key. Under Application restrictions, choose HTTP referrers and add this site's address only.
  3. Set a budget alert and a daily quota so a leaked key can't run up charges.

Your key stays in this browser. It is sent only to Google.

Leaderboard

Community maps

Maps are lists of places made by players. Vote to lift the best to the top and sink the bad ones. Play uses the mode and imagery chosen on the Play tab.

Create a map

Click the map to add a place, or paste one "latitude, longitude" per line. You need at least 5 places.

Duel

Two players, same places, 6,000 health each. After every round the lower score loses health equal to the difference. Uses the mode and imagery chosen on the Play tab.

Your data

Your account is a Nostr key stored in this browser. If you clear your browser data the account is lost, so use Back up key on the Play tab to save it, and Import key to use it on another device.
